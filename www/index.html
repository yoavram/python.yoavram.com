Workshops

Nine workshops, each of which can be taught on its own or combined with others. Every workshop is tailored to your team.

Workshops can also be held online, on Zoom or Teams, in 3-hour meetings.

Custom topics on request.

Scientific Python and Data Science

For engineers and developers new to Python, including engineers moving from MATLAB®.

  • Write idiomatic Python for numerical work.
  • Analyse data, signals, images and time series with NumPy, pandas and SciPy.
  • Test your code and set up reproducible environments.

Typical length: 2–4 days

Modelling and Simulation

For engineers and scientists who model dynamic systems.

  • Build and solve ODE and discrete-time models, and analyse their stability.
  • Simulate stochastic systems, and make the simulations fast.
  • Fit models to data with maximum likelihood.

Introduction to Deep Learning

For developers and engineers who want to really understand neural networks.

  • Derive neural networks from maximum likelihood and linear and logistic regression.
  • Build and train feed-forward networks and CNNs for images and time series.
  • Explain what backpropagation is doing and why a model fails to train.

Typical length: 3 days

Advanced Deep Learning

The next step after the introduction: transfer learning, self-supervised generative models, imbalanced data and calibration.

  • Adapt pretrained models with transfer learning and fine-tuning.
  • Learn from unlabelled data with self-supervised generative models: autoencoders, GANs and normalizing flows.
  • Handle imbalanced data, and calibrate predicted probabilities.

Typical length: 2 days

Bayesian Inference

For engineers and scientists who fit models to data.

  • Explain Bayesian inference and run MCMC.
  • Fit dynamic models with Bayesian inference.
  • Infer parameters from simulations, with ABC and neural density estimation.

Typical length: TODO(Yoav): duration

Machine Learning Evaluation

For teams working with ML models.

  • Design held-out evaluation that matches real use.
  • Find leakage and selection bias before your customers do.
  • Compare models honestly.

Typical length: 1–2 days

Open-Set Learning: Metric Learning, Zero-Shot and Re-Identification

For teams whose models must handle classes, individuals or items they have not seen.

  • Explain closed-set versus open-set classification, and evaluate on classes the model never saw.
  • Classify zero-shot with CLIP, and learn your own embedding with metric learning.
  • Build and evaluate a re-identification pipeline.

Typical length: 2 full days

LLMs from First Principles

For engineers and technical managers.

  • Build tokenisation, a transformer and a training loop small enough to run on a laptop.
  • Pretrain a small language model.
  • Fine-tune it to follow instructions.
  • Apply reinforcement learning from rewards, and see how reward hacking arises.
  • Build a software-engineering (SWE) agent.

Typical length: 2 days

ML with Coding Agents

For R&D teams adopting AI-assisted coding.

  • Specify tasks so an agent's output can be checked.
  • Review and verify agent-written code.
  • Deliver a ML analysis with an agent without silent errors.

Typical length: 1 day

How I teach

  • Hands-on and interactive. Workshops are taught in Jupyter notebooks, in VS Code.
  • Short and long exercises. Short exercises to practise each idea, and longer ones to put several together.
  • No slides. All the code is shown and discussed.
  • Theory and application. Each topic is taught together with how to apply it.

ML with Coding Agents

For R&D teams adopting AI-assisted coding.

What you will be able to do

  • Specify tasks so that an agent's output can be checked.
  • Review and verify code written by an agent.
  • Recognise and avoid errors that look plausible but are wrong.
  • Complete a full ML analysis with an agent, on your own data.

Prerequisites

Python experience, some familiarity with machine learning, and access to a coding agent. Any one will do.

Outline

Duration: 1 day, on-site or remote.

  1. Morning: specifying tasks, reviewing and verifying agent output, avoiding silent errors
  2. Afternoon: a full ML analysis done with an agent, on your own data

Sample materials

  • Penguin species with Python
  • Coral bleaching with R
  • Fish survey exercise
  • Species photo-identification with Python

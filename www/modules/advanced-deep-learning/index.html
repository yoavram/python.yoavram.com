Advanced Deep Learning

What you will be able to do

  • Handle imbalanced classification.
  • Adapt pretrained models with transfer learning and fine-tuning.
  • Check whether predicted probabilities are calibrated, and attach conformal prediction intervals to a model's predictions.
  • Learn from unlabelled data with self-supervised generative models (autoencoders, GANs and normalizing flows), and explain what each one learns: a representation, a way to sample, or the data distribution.

Prerequisites

An introduction to deep learning, for example Introduction to Deep Learning, and Python experience.

Format and duration

2 days, on-site or remote. Hands-on, with exercises.

Outline

Four half-days, six topics in this order. The last three are all self-supervised learning: the model learns from the data itself, without labels.

  1. Imbalanced classification
  2. Calibration and conformal prediction
  3. Transfer learning and fine-tuning
  4. Autoencoders: learning a representation
  5. Generative adversarial networks (GANs): learning to sample
  6. Normalizing flows: learning the data distribution
